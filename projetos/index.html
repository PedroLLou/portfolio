Em andamento, e feitos em dupla

Dois sistemas grandes sem estudo de caso ainda. Os dois foram feitos com Igor Ferreira, meu parceiro na Kyber, e cada linha diz quem fez o quê.

Parou num NO-GO documentado: 11 dos 30 itens de prontidão dependem de terceiros, como pentest e encarregado de dados.

IV

Ferramentas abertas

Pedaços que saíram dos produtos e servem sozinhos. Código público, testes que rodam sem instalar nada. Versões iniciais, ainda fora do npm.

  1. Node.js

    asaas-webhook-kit

    Inbox durável e idempotente para webhooks de pagamento do Asaas: deduplica, ordena por cobrança, aplica em transação e testa a sua política, inclusive com o processo morrendo no meio. Zero dependências. 61 testes e 9 cenários de conformidade.

    Node.js, SQLite, TypeScript GitHub ↗
  2. Agentes de IA

    agent-handoff

    Formato verificável para passar trabalho entre agentes: separa o que foi medido do que foi só relatado e confere por sha256 que o Markdown bate com o JSON. É o que eu uso entre Codex e Claude. 71 testes.

    Node.js, JSON Schema, CLI GitHub ↗
  3. Texto

    numeros-ptbr

    Encontra os números de um texto em português, inclusive por extenso, em legendas e transcrições, e aponta os que não têm fonte registrada. Nasceu de revisar roteiro de vídeo. 88 testes.

    Node.js, SRT GitHub ↗
  4. Skill

    humanizador

    Skill para agentes que tira a cara de IA de textos em português sem inventar fatos: 42 padrões, do "crucial" ao conectivo empilhado. Adaptação do blader/humanizer, instalável no Claude Code.

    Python, Claude Code GitHub ↗
  5. Carreira

    gerador-curriculo

    Kit que usa IA para gerar currículos sob medida por vaga, em PDF e DOCX. Bilíngue. É o que gera os dois PDFs deste site.

    Python, Markdown, Claude Code, MCP GitHub ↗
