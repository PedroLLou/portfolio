Two large systems without a case study yet. Both were built with Igor Ferreira, my partner at Kyber, and each row says who did what.

IV

Open tools

Pieces that came out of the products and stand on their own. Public code, tests that run without installing anything. Early versions, not on npm yet.

  1. Node.js

    asaas-webhook-kit

    Durable, idempotent inbox for Asaas payment webhooks: dedupes, orders per payment, applies in a transaction and tests your own policy, including the process dying midway. Zero dependencies. 61 tests and 9 conformance scenarios.

    Node.js, SQLite, TypeScript GitHub ↗
  2. AI agents

    agent-handoff

    A verifiable format for handing work between agents: keeps measured claims apart from merely reported ones and checks via sha256 that the Markdown matches the JSON. It is what I use between Codex and Claude. 71 tests.

    Node.js, JSON Schema, CLI GitHub ↗
  3. Text

    numeros-ptbr

    Finds every number in Brazilian Portuguese text, spelled-out ones included, in subtitles and transcripts too, and flags those without a recorded source. It came out of reviewing video scripts. 88 tests.

    Node.js, SRT GitHub ↗
  4. Skill

    humanizador

    Agent skill that removes AI tells from Brazilian Portuguese text without adding facts: 42 patterns, from "crucial" to stacked connectives. Adapted from blader/humanizer, installable in Claude Code.

    Python, Claude Code GitHub ↗
  5. Career

    gerador-curriculo

    Kit that uses AI to generate job-tailored resumes in PDF and DOCX. Bilingual. It is what produces the two PDFs on this site.

    Python, Markdown, Claude Code, MCP GitHub ↗
